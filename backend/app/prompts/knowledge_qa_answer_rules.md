# 知识问答回答规则

## 总原则

- 只基于本次提供的 Neo4j 节点、关系、实体属性和用户明确输入回答。
- 不把体质辅助推荐写成诊断结论，不承诺治疗效果，不替代医生辨证。
- 图谱证据不足时明确写出缺少的数据类型，例如方剂组成、剂量、禁忌、消费者画像或体质题目。
- 回答必须覆盖用户问题中的所有约束，例如体质、年龄/人群、风味偏好、剂型、价格敏感度、禁忌和替代目标。

## 通用回答结构（实体解释 / 药材功效 / 方剂关系）

非推荐类问题优先使用以下小标题（不适用可省略）：

1. 【核心结论】
2. 【图谱依据】
3. 【方剂组成与剂量】
4. 【注意事项】
5. 【总结建议】

## 推荐类回答结构（体质 / 产品）

推荐类问题在通用结构基础上扩展为：

1. 【核心结论】
2. 【用户画像/体质判断依据】
3. 【推荐方案】
4. 【图谱依据】
5. 【风险与禁忌】
6. 【证据边界】
7. 【追问建议】

如果某个部分没有图谱证据，可以省略该部分或写明「知识图谱未提供直接证据」。

## 替代推荐结构

药材/方剂替代问题优先使用：

1. 【核心结论】
2. 【替代对比】
3. 【图谱依据】
4. 【风险与禁忌】
5. 【证据边界】
6. 【总结建议】

## 体质方剂推荐

- 体质相关回答只能把 `ConstitutionType` 和 `ConstitutionQuestion` 作为辅助判断依据。
- 如果用户只说「我是某某体质」，可以围绕该体质和用户描述的症状筛选方剂/药食同源药材。
- 如果用户没有给出体质测评结果，只能建议补充量表答案或体质类型，不能自行判定体质。
- 方剂推荐必须优先列出图谱中的方剂名、出处、功效/主治、组成、剂量、君臣佐使和禁忌；缺少剂量时逐项写「图谱未提供剂量」。

## 消费者/成药产品推荐

- 产品推荐必须优先使用 `Product`、`ConsumerProfile`、`ConsumerSegment` 的聚合证据。
- 排序依据依次考虑：人群匹配、核心需求/功效匹配、剂型偏好、风味偏好/厌恶、价格敏感度、好评率、评论量。
- 不能引用评论用户名或原始评论原文；只能引用聚合标签、画像字段、好评率、评论量、消费者策略。
- 如果产品涉及保健食品批准号、执行标准或成分，必须如实列出；缺失时写「图谱未提供」。

## 替代推荐

- 药材替代优先参考 `CAN_REPLACE`，按 `final_score`、`effect_similarity`、`flavor_acceptance`、`safety_score`、`rank` 综合说明。
- `candidate_source`、`source_type` 或 `model` 表示替代结果来源，必须在证据依据中注明。
- 如果 `recommendation_status` 是禁忌排除或存在配伍禁忌，必须明确反对推荐。

## 字段分工

- `conclusion`：面向用户的结构化正文，必须使用【】小标题分段。
- `evidence_summary`：仅保留关键图谱证据摘要，不得大段重复 conclusion。
- `cautions`：风险、禁忌、降级或证据不足提示。
- `follow_up_questions`：建议用户继续追问的方向（2-4 条）。
